# Joel Lo — personal website

The live portfolio at https://joelloliangze.com is now a standalone static site, maintained directly in this repository. It does not require Hugo or a cross-repository deploy key.

- `index.html`: homepage content and structure
- `portfolio/site.css`: responsive design
- `portfolio/site.js`: progressive enhancement
- `images/`: existing personal photography
- `blog/` and `gallery/`: preserved earlier pages
- `CNAME`: custom domain; keep this file

GitHub Pages publishes this repository's main branch. Edit these files and push to main to publish. Preview locally with `python -m http.server 8000`.

Career information is based on Joel's LinkedIn export supplied on 14 October 2026. Previous Hugo source remains in aerodromic.github.io.hugo as an archive; its publishing workflow should remain disabled to avoid overwriting this site.
